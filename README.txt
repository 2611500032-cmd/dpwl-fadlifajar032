UTS Pemrograman Web - Website Absensi Mahasiswa
Institut Sains dan Bisnis Atma Luhur

Cara pakai:
1. Ekstrak folder ini, ganti nama folder menjadi UTS-PW-NIM (contoh: UTS-PW-41230123).
2. Buka folder di VS Code (File > Open Folder).
3. Jalankan index.html dengan Live Server atau klik dua kali file-nya.

Yang perlu diganti:
- Cari "123" lalu ganti dengan 3 digit terakhir NIM (Ctrl+H) di index.html dan buku-tamu.html
- Email, telepon, dan link sosial media di bagian Kontak dan Footer
- Foto: taruh di folder images/ lalu ubah src di index.html
